## What I'm working on

**[postgres-pgtap-test-framework](https://github.com/sergeiboikov/postgres-pgtap-test-framework)** — a
unit-testing framework for PostgreSQL built on **pgTAP**, with statement coverage reported by
**Piggly**. Runs in Docker against either a throwaway container or an existing database, and ships
with a Gilded Rose demo so you can see a green test run in one command.

**[sqlfluff-extended-pack](https://github.com/sergeiboikov/sqlfluff-extended-pack)** — a SQLFluff
plugin enforcing naming conventions from the Postgres SQL Format Guidelines: 11 rules covering
constraints (`pk_`, `fk_`, `chk_`, `uc_`, `df_`), functions and their parameters, and views.

**[poc-pg-mutation-testing](https://github.com/sergeiboikov/poc-pg-mutation-testing)** — a prototype
exploring mutation testing for PL/pgSQL: if your tests still pass after the code is deliberately
broken, the tests are the problem.

**[postgresql-course](https://github.com/sergeiboikov/postgresql-course)** — course materials from
*Intermediate SQL for Data Scientists*.
